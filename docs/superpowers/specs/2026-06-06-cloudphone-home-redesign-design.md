# 云机体检首页改版设计

## 目标

把 Android App 首页从“诊断文本堆叠页”改成“云机状态控制台”。首页只回答一个问题：这台云手机当前是否已经接入、可控、可交给本地 Agent 使用。

选定视觉方向为“玻璃状态面板”：浅色背景、半透明状态卡、短状态词、清晰状态色。整体应像专业远程设备控制台，而不是原始日志或测试工具。

## 信息架构

首页展示高层状态：

- 设备接入状态：设备 ID、机型、Android 版本、App 版本。
- 控制能力状态：Relay、Root、ADB、前台应用。
- 健康/就绪结论：例如“云机已接管”“控制通道就绪”“需要处理权限”。
- 高频操作：复制接入信息、复制 JSON、刷新状态、启动/停止 Relay、进入诊断详情。

详细信息从首页下沉：

- 系统明细、Root stdout/stderr、权限列表、已安装 App 列表、网络测试结果、JSON 原文不在首页直接铺开。
- 第一版可用折叠详情区承载这些信息；后续如果需要再拆成独立详情页。

## 首页布局

顶部：

- 小标题：`云机体检`
- 状态胶囊：`Online` / `Offline` / `Collecting`
- 副标题：显示机型、Android 版本、最后采集时间。

主视觉：

- 大标题：根据诊断结果动态显示，例如：
  - `云机已接管`
  - `控制通道就绪`
  - `需要处理权限`
  - `Relay 未连接`
- 圆形就绪分数或状态环，分数由 Relay、Root、ADB、权限、网络几个维度粗略计算。
- 一句短说明，避免长日志。

核心指标：

- `Relay`：在线、未连接、重连中。
- `Root`：Ready、Unavailable。
- `前台`：从 snapshot 能力或最近报告展示，未知时显示 `Unknown`。
- `ADB`：Bridge Ready、Disabled、Unknown。

操作区：

- 主按钮：`复制接入信息`
- 次按钮：`复制 JSON`
- 小按钮：`刷新`、`开启 Relay` / `停止 Relay`、`诊断详情`

详情区：

- 默认折叠。
- 展开后显示原有机器信息、Root、权限、网络、App 列表和 JSON 文本。
- JSON 原文仍可复制，但不再作为首页视觉重点。

## 视觉规范

- 背景：浅色冷调，避免大面积纯白。
- 卡片：半透明白色、细边框、轻阴影，圆角克制。
- 状态色：
  - 正常：青绿色。
  - 警告：琥珀色。
  - 失败：红色。
  - 未知：灰色。
- 文案：短句优先，状态词优先；长诊断信息只进入详情区。
- 字体：沿用系统中文字体，确保 Android 7+ 兼容和 APK 轻量。

## 代码边界

本次只改 Android App UI 和 `MainActivity` 的渲染组织：

- 保留现有 collector、RelayService、Root API、ADB bridge 行为。
- 不改变命令协议。
- 不引入 Compose。
- 不引入新图片资源或重型依赖。
- 继续使用 Kotlin + XML/View。

## 验收标准

- 首页首屏不再出现大段机器信息、Root stdout/stderr、App 列表或 JSON 原文。
- 首页能一眼看到 Relay、Root、ADB、设备基本状态。
- 复制 JSON 功能保留。
- 复制接入信息可直接给本地 Agent 使用。
- 详情区仍能查看原有诊断信息。
- Android 7.0+ 兼容，不使用高版本专属 UI API。
- App 能正常构建并生成 APK。
